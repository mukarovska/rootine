# Rootine

Rootine is a plant care web application designed to help users keep their houseplants healthy and build consistent plant care routines.

The goal is to make plant care easier by keeping plant information, care schedules, and reminders in one place.

> **Work in progress** — Rootine is currently under development.

## Features

Planned features include:

- Manage a personal collection of houseplants
- Store plant details and growing conditions
- Track watering and other plant care activities
- Set reminders for upcoming care tasks
- Keep track of plant care history

## Tech Stack

- **React**
- **TypeScript**
- **Tailwind CSS**
- **Vite** — development server and build tool
- **Supabase** — database and backend services
- **ESLint** — code linting
- **Prettier** — code formatting
- **Husky & lint-staged** — pre-commit checks
- **GitHub Actions** — continuous integration (CI)
